# Импорт выбранных упражнений для груди

Файл `selected-chest-exercises.json` содержит 30 одобренных упражнений с русскими названиями и инструкциями. Исходный идентификатор используется только для проверки набора и не записывается в таблицу `exercises`.

## Безопасный запуск

1. Сделайте резервную копию базы данных.
2. Примените миграцию `migrations/004_exercise_instruction.sql`.
3. Выполните предварительную проверку: `npm run import:chest-exercises`.
4. Запустите импорт: `npm run import:chest-exercises -- --apply`.

Повторный запуск безопасен: уже добавленные упражнения пропускаются.

## Откат

Сначала выполните проверку: `npm run rollback:chest-exercises`.

Для удаления добавленных упражнений: `npm run rollback:chest-exercises -- --apply`.

Скрипт удаляет только глобальные упражнения из этого набора, которые ещё не используются в планах тренировок или журналах подходов. Используемые записи сохраняются. После отката данных при необходимости примените `migrations/rollback/004_exercise_instruction.sql`; это удалит колонку `instruction` и её данные для всех упражнений.
